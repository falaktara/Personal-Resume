# Personal Resume Website

This project is a personal resume website created as part of my Frontend Web Developer Internship at Barakah TechLabs.

It presents my educational background, technical skills, projects, and personal information through a clean and creative web design.

* HTML5
* CSS3

## Features

* Semantic HTML structure
* Personal introduction
* Educational background
* Technical skills
* Projects section
* Contact information
* Responsive styling

## Purpose

The purpose of this project is to practice semantic HTML and CSS styling while creating a personal online resume.
